# Assets

Screenshots referenced from the top-level READMEs and the marketplace listing.
Drop the files here with these exact names — nothing else in the repository
needs to change.

| File | Referenced by | What it shows |
|------|---------------|---------------|
| `panel.png` | `README.md`, `README.zh.md` | The panel open, with a blocked card, one or two working cards and an idle one |
| `chip.png` | `README.md`, `README.zh.md` | A tight crop of the bar chip, several agent marks visible |
| `notification.png` | optional, not currently embedded | The completion notification next to the chip |

One more file lives outside this directory:

| File | Referenced by | What it shows |
|------|---------------|---------------|
| `../preview.png` | the marketplace listing card | A wide crop of the open panel with the chip visible; the only image the marketplace itself reads |

Limits, for all of them: 50 MB and 40 megapixels each. Normal captures need no
manual resizing or compression — the marketplace optimizes the preview itself.
Prefer PNG for the bar chip (small text and glyph edges), and crop rather than
scale down so the marks stay readable.
