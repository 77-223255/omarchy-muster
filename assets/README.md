# Assets

Screenshots referenced from the top-level READMEs and the marketplace listing.

Suggested captures, both from the real desktop:

| File | What it shows |
|------|---------------|
| `panel.png` | The panel open, with a blocked card, one or two working cards and an idle one |
| `chip.png` | A tight crop of the bar chip, several agent marks visible |
| `notification.png` | The completion notification next to the chip |

A root `preview.png` (not in here) is what the marketplace uses as the listing
card; it is optional and optimized automatically. Keep each file under 50 MB and
40 megapixels.
